LiteOC — 安装

【推荐:双击 .pkg 安装(无需终端)】
  1. 下载:https://github.com/ren2019/LiteOC/releases/latest → 取最新 LiteOC-<ver>.pkg
  2. 双击 → 按向导输入本机登录密码(安装器以 root 装:vpnctl、内置 openconnect、免密 sudoers、App)
  3. 首次若被 Gatekeeper 挡:系统设置 → 隐私与安全性 → 「仍要打开」(GUI,不开终端;因 .pkg 为 ad-hoc 匿名签名、未公证)
  完成后:启动台 LiteOC → 菜单「配置…」填 网关/用户/组(证书留空首次自动获取)→ 「设置 PIN…」存 PIN → 「连接」

【源码 / 开发(需终端,需 Homebrew)】
  cd gui && ./build.sh && sudo sh setup-root.sh
  (setup-root.sh:缺 openconnect 时 brew install;装 vpnctl + 免密 sudoers + App)

要求:macOS 12+(Apple Silicon / arm64)
排错 / 说明:https://github.com/ren2019/LiteOC
